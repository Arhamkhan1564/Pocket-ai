# Offline model validation for v1.2

These records show actual model execution and narrow parity checks on a Linux x86_64 development host. They do **not** establish Android or itel A25 Pro performance, fluent-speaker acceptance, representative-corpus accuracy, or clinical safety. APK identity, signing, Android tests and build results belong in the separate build report.

The baseline separates multilingual passage search, English-to-Urdu/Punjabi translation, conditional English generation and speech recognition. Exact resources, sizes, hashes and directions are recorded in [the pinned manifest](../app/src/main/assets/offline-model-manifest.json). No provider translation API was used in these model trials.

One recorded two-sentence source was: “The tablet contains 250 mg of paracetamol. Do not use during pregnancy.” IndicTrans2 produced:

- Urdu: `گولی میں 250 ملی گرام پیراسیٹامول ہوتا ہے۔ حمل کے دوران استعمال نہ کریں۔`
- Punjabi Gurmukhi: `ਗੋਲੀ ਵਿੱਚ 250 ਮਿਲੀਗ੍ਰਾਮ ਪੈਰਾਸੀਟਾਮੋਲ ਹੁੰਦਾ ਹੈ। ਗਰਭ ਅਵਸਥਾ ਦੌਰਾਨ ਇਸ ਦੀ ਵਰਤੋਂ ਨਾ ਕਰੋ।`

These examples demonstrate specific retained content; they are not expert medical approval. The [full output record](offline-v1.2-model-results/translation-python-summary.txt) retains raw text, processing details and limitations. The smaller Marian candidate was rejected before integration because its trials corrupted quantities/identifiers and omitted content.

There is no direct Shahmukhi translation target in the selected IndicTrans2 checkpoint. The Shahmukhi wrapper fixtures apply a separately labelled Gurmukhi-to-Shahmukhi script conversion to genuine Punjabi output. Their successful deterministic checks establish neither natural Shahmukhi spelling nor fluent-speaker accuracy. Urdu is not used as a substitute for Punjabi.

Host measurements also differ by harness. Python translation's kernel-reported peak RSS was about 415 MiB; the canonical JVM tensor-kernel harness reported 306,393,088 bytes. The composed tokenizer/model log recorded a high-water mark of 393,388 KiB. SmolLM2 sampled about 347 MiB and took 13–17 seconds per short request, including its request path. These are distinct host processes and workloads; they are not predicted Android memory or latency.

A later [inference build-graph check](offline-v1.2-model-results/sentencepiece-inference-build-graph.json) records the updated CMake fingerprint and explicit JNI target selection. SentencePiece trainers and command-line executables are excluded; the checked tokenizer C++ behavior is unchanged. Final APK compilation remains a separate build result.

Remaining acceptance includes a real 2 GB ARMv7 phone, larger document collections, varied speakers and texts, source-preservation failures beyond the controls above, interruption/low-memory behavior, installed offline TTS voices and sustained screen-off operation. Model metadata, a passing parity fixture or an available CPU ABI cannot establish those results.

The [evidence index](offline-v1.2-model-results/index.json) records copied reports, checksums and source hashes where available. It contains only small JSON/TXT records—no weights, caches, classes, JARs or native libraries. Reports are snapshots of the checked source; later edits require their own verification. An older tokenizer-probe note about unpackaged validation inputs describes that probe, while the current baseline's bundle membership is defined by the pinned manifest.
