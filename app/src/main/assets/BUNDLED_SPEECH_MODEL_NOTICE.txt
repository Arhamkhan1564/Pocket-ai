This APK includes the speech model so supported devices do not need to
download a separate file before voice input. At first launch Pocket AI verifies
and copies the model to app-private storage, then selects it only when no valid
speech model is already selected. The application performs no network requests.

Urdu and Punjabi language identifiers are supported by the inference runtime.
Recognition accuracy, script output, latency, microphone quality, and memory
use depend on the device and speech. This inclusion does not add a TTS voice,
a translation pack, or a generative language model. Native inference is included
for ARM64, x86_64 and 32-bit ARMv7 with NEON. The running native library checks
capability; unsupported hardware keeps saved-knowledge text and installed offline
TTS. A 32-bit process has tighter address-space limits, so larger models can fail
even with free storage. Actual 2 GB target-phone performance remains unverified.
