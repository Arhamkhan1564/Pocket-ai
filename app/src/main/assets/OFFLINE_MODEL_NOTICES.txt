Pocket AI 1.3 voice preview offline model resources

The exact file names, byte sizes, SHA-256 digests, pinned public download URLs,
model roles and directions are in offline-model-manifest.json. Resources are
bundled into this APK from an external build-assets directory. No application
runtime download, account, cloud inference or provider translation API is used.
Source distributions omit standalone weights; scripts/fetch-offline-models.py
reconstructs and verifies the pinned assets before an Android build.
The bundle contains 17 files in seven packs, totaling 899,719,726 bytes.
This is a model-asset total, not APK size or installed-storage use.

The int8 model and 65-token vocabulary produce Gurmukhi. The runtime uses
bounded 12-second windows and merges raw frames before global CTC decoding.
Shahmukhi is a separately labeled display conversion; it is not a direct
Shahmukhi acoustic model or Urdu relabeled as Punjabi. Four host speech clips
contained substantial word/name errors. Four non-speech controls returned empty
text. All manual Punjabi results require editable review. These checks do not
establish broad language, clinical or 2 GB phone acceptance.

7. Speech-presence detector

Upstream: snakers4/silero-vad, version 6.2.3
Pinned revision: 5cd7945676eb32225748052e2e6a0580e4686a08
Source: https://github.com/snakers4/silero-vad
Model: silero-vad.onnx, 2,327,524 bytes
SHA-256: 1a153a22f4509e292a94e67d6f9b85e8deb25b4988682b7e174c65279d8788e3
License: MIT; Copyright (c) 2020-present Silero Team
Full license: licenses/SILERO_VAD_MIT.txt

This offline detector runs before every Whisper model and is closed before
Whisper loads. Its official reference pipeline, with threshold 0.5 and 250 ms
minimum speech, accepted four Urdu/two English recordings and rejected three
non-speech controls. The canonical Kotlin gate matched all nine decisions and
every frame probability exactly on the host. Device behavior remains unverified;
see documentation/VOICE-VALIDATION-1.3.md. Likely speech is not proof that recognized
words, names, numbers or medical meaning are correct.

Each recording fixes its backend, language, script and draft destination before
capture. Manual Urdu/Punjabi results require editing/review before entering the
captured draft; sending or saving still needs the user's action. Original
recognition remains available beside labeled Shahmukhi conversion. Hands-free
turns use unreviewed transcripts and have additional limitations. No microphone,
all-Android, 2 GB phone, fluent-speaker or clinical acceptance is implied.
