Pocket AI offline baseline model resources

The exact file names, byte sizes, SHA-256 digests, pinned public download URLs,
model roles and directions are in offline-model-manifest.json. Resources are
bundled into this APK from an external build-assets directory. No application
runtime download, account, cloud inference or provider translation API is used.
Source distributions omit standalone weights; scripts/fetch-offline-models.py
reconstructs and verifies the pinned assets before an Android build.
