API key or in-app download. Android offline TTS voices are separate system resources.

Installation and your saved knowledge:
1. Keep your existing Pocket AI app. The original signing key is unavailable;
   this preview installs separately as com.pocketai.voicepreview.
2. In the old app, unlock administration and export a knowledge backup.
   Keep that plaintext backup private.
3. Install this APK, open 'Pocket AI Voice Preview', set its own PIN/recovery
   code, then import the saved knowledge backup. Existing old-app data stays intact.
4. Allow several GB of free storage. Included resources are prepared locally
   from the APK; Urdu/Punjabi speech resources prepare before the microphone starts.
5. Use included automatic recognition for English tiny, Urdu base and Punjabi CTC.
   Manual Urdu/Punjabi results require editable review. Shahmukhi conversion is labeled.

Check every recognized name and quantity. Speech errors remain in host fixtures.

are pending. No universal Android support or safe personal medication selection is claimed.
Supported targets: Android 6/API 23+,ARM64, ARMv7 with NEON, x86_64, subject to free memory.
